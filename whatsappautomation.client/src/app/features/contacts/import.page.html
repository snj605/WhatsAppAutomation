1. Get your contacts in Excel

All your saved contacts, with a column for each of your occasions (Asthi, Anniversary…) and contact fields (City…). Change any cell, add new people in new rows, then import it below: saved numbers are updated, new numbers are added.

  • Phone* with country code, e.g. +919876543210: how rows are matched
  • Name (English / Hindi / Gujarati): the one in the contact's language is required
  • Language en, hi or gu; Category one name; Groups comma-separated (added)
  • Each occasion: DD-MM or DD-MM-YYYY; each field in its own column
  • An empty cell keeps what is saved; removing a row does not delete the contact

Use .xlsx for Hindi and Gujarati. If you use CSV, save it as "CSV UTF-8".
